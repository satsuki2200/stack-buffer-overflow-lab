# step1：メモリ＝箱の列、という感覚

> この回はコードなし。頭の中に「土台の絵」を作るだけ。

## つかむこと

コンピュータのメモリは、**番号（番地）のついた箱が一列に並んだもの**だとイメージする。

- プログラムが「名前を入れる場所」などを用意するとき、箱を何個か予約する。
  この予約した箱の並びを **buffer（バッファ）** と呼ぶ。箱の数は最初に決まっている。
- buffer に収まる量ならOK。でも**予約した数より多く詰め込むと、あふれた分が隣の箱に書き込まれてしまう**。
  これが **オーバーフロー（あふれ）**。
- 隣の箱には、たまたま「この処理が終わったらCPUは次どこへ戻るか」という**戻り先のメモ**が置いてある。
  ここを上書きできると、**プログラムの行き先を乗っ取れる**。これが攻撃の核心。

## 正常 vs 溢れた（イメージ）

```
正常：  [こ][ん][に][ち][は][ ]   [ 正しい戻り先メモ ]   ← そのまま無事
溢れ：  [A ][A ][A ][A ][A ][A ]  [ 攻撃者が決めた行き先 ] ← ここが乗っ取りの鍵
         └─ buffer（6箱）─┘        └─ 隣の箱 ─┘
```

## この回のメモ

- 「箱」はポインタそのものではない。箱は「**番地（位置）** ＋ **中身（値）**」の2つを持つ。
- **ポインタ**とは「**中身が、別の箱の番地になっている箱**」のこと。
- 攻撃で書き換える「戻り先メモ」は、中身が番地（＝ポインタ的な値）。だからそこが急所。

→ 次（step2）で、この「番地」と「中身」を本物のCプログラムで表示して確かめる。
