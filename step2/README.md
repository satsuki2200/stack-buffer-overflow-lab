# step2：はじめてのC — 変数は「番地＋中身」

> ここで初めてCを書いて、コンパイル・実行した。

## やること

箱を1個用意して、その**番地**と**中身**を実際に表示させる。step1 の絵が本物のプログラムで見える。

## コード（step2.c）

```c
#include <stdio.h>          // ① printf を使うための宣言を差し込むおまじない

int main(void) {            // ② プログラムは main から始まる
    char c = 'A';           // ③ 箱を1個用意し、中身に 'A' を入れる ＝ 変数
    printf("中身=%c  番地=%p\n", c, &c);  // ④ 中身(c) と 番地(&c) を表示
    return 0;
}
```

ポイント：
- `char c = 'A';` の `char` が「1箱ぶんの入れ物」。名前 `c`、中身 `'A'`。
- `&c` の **`&`** が主役。「`c` という箱の**番地を教えて**」の意味（アドレス演算子）。
  - `c` ＝ 中身、`&c` ＝ 番地。step1 の「番地 vs 中身」と完全対応。

## ビルドと実行

```bash
# Linux
gcc -g -O0 -o step2 step2.c
./step2

# Mac（Command Line Tools を入れてあれば cc でOK）
cc -g -O0 -o step2 step2.c
./step2
```

出力例：

```
中身=A  番地=0x7ffcb2aa38b7
```

- `中身=A` … ③で入れた 'A'。
- `番地=0x7ffc...` … c という箱の番地。頭の `0x` は「16進数ですよ」の印。

## 発見：番地は毎回変わる

同じプログラムを何回か走らせると、**中身は毎回 A なのに、番地は毎回バラバラ**。

```
中身=A  番地=0x16f57f06b
中身=A  番地=0x16d50706b
中身=A  番地=0x16d06f06b
```

これは **ASLR** という防御機能（箱の置き場所を毎回ランダムにずらして、攻撃者に番地を読ませない）。
step5 の最終的な「ラスボス」的防御。今は「番地は毎回変わる。しかも誰かがわざと守っている」とだけ覚えておく。

> メモ：Mac の番地が `0x16...` 範囲なのは Apple Silicon（ARM）の特徴。
> Linux(x86-64) では `0x7ffc...` のような範囲になる。

## 補足：`#include <stdio.h>` って何？

- コンパイラは関数を呼ぶ前に、その関数の「**形（名前・引数・戻り値）＝宣言**」を知る必要がある。
- `#include <stdio.h>` は、printf などの**宣言（メニュー表）**を自分のファイルに差し込む命令。
  実際の処理コード（厨房）は C標準ライブラリ(libc)にあり、最後に自動でつながる（**リンク**）。
- Go の `import "fmt"` は宣言も実体も1つで解決してくれる。
  C は古いので「**ヘッダ（宣言）＋ ライブラリ（実体）**」が分かれている。`#include` はその宣言の半分。
- `#include` の実体は「そのファイルの中身をここに丸ごとコピペする」という原始的な命令。
